# Analytics — Meta (Facebook + Instagram)

## Cuentas a conectar
- Facebook Page: Nexus Suite / NexusAI / por desarrollo
- Instagram Business accounts por desarrollo
- Meta Ads Manager: campañas de paid media

## Métricas a trackear
### Orgánico
- Alcance, impresiones, engagement rate
- Posts con mayor performance por formato (Reel, carrusel, imagen)
- Crecimiento de seguidores por mes

### Paid (Ads)
- CPM, CPC, CTR
- CPL (costo por lead)
- ROAS por campaña
- Audiencias que mejor convierten

## API
- Meta Graph API v18+
- Requiere: App ID, App Secret, Page Access Token (long-lived)
- Scopes: pages_read_engagement, ads_read, instagram_basic, instagram_manage_insights
